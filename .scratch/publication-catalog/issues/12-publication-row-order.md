# What order are the publication rows in?

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by:
Assignee: wayfinder

## Question

The site is one publication table. What is the default order of its rows?

Invoke grilling and domain-modeling.

## Answer

The user chose title order. The ledger lists publications by title, A to Z. The date stays a column and does not set the order. No. is that row's place in the list, starting at 1.

The prototype's "date, then title" line was only so the columns could be seen. It is not this order.

The **Row order** term is locked in `CONTEXT.md`.

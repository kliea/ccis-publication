# What does the spec assume the site is?

Type: grilling
Label: wayfinder:grilling
Status: resolved
Blocked by:
Assignee: wayfinder

## Question

The catalog rules for the table are settled. The site shows one snapshot of 2025 publications. A refresh replaces that snapshot when someone asks. What does the spec assume the site is built and hosted as?

Invoke grilling and domain-modeling.

## Answer

The user chose a static site. The snapshot is built into the pages. A refresh rebuilds those pages. The spec names no account and no particular host. Any host that serves files is enough.

**Site** and **Refresh** are locked in `CONTEXT.md`.
